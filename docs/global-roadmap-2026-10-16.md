1. 用户发起的多步目标在用户离开、内核重启、审批跨小时、外部响应丢失、验收不过五种情况下都走到已知状态（W1 场景 S1–S10 在主机通过）；
2. 任务专用的 Worker 组合在授权内直接运行、越权的被拒或转审批，一步失败后规划器换路达成（W2 验收）；
3. 管理员 Agent 在对话里把一个新系统接进生产工作区，人只做录凭证、审变更、点应用，且 §5.7 的防自扩权守卫全部通过（W3 验收）；
4. `STATUS.md` §3 记一行「S11 关闭」，W4 / W5 的余项按触发条件挂到下一阶段。
