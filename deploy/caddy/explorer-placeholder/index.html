This is the placeholder page for the platform's Explorer mount (design doc §9.5; docs/development-tasks.md §S3.5). The Explorer front-end is a third-party static bundle built on the host, not shipped in this image by default — see explorer/README.md and docs/runbooks/host-explorer.md.
